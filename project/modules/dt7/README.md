# DT7 / DR16 遥控器

独立模块，接口与 `leg_main` 一致。本项目编译此模块，但应用层使用 [VT13](../vt13/README.md)，尚未给 DT7 分配或初始化 UART。

- 调用 `DT7_Init(huart)` 前须配置 100000、9 位字长、偶校验、1 停止位、接收使能（8 个有效数据位）。参数不符返回 `nullptr` 并记录错误，不注册接收。
- 数据由 `dt7_data` / `DT7_RC_*` 读取；通道已减中位，范围为 ±660。摇杆、拨轮、左右开关定义见 [dt7.h](dt7.h)。
- 仅完整 18 字节帧、五个通道均在有效范围、两个开关均为 1/2/3 时更新和喂狗；无效帧不覆盖上次数据。不另加流式拆包。
- 初始化保持离线，首个有效帧上线并置 `dt7_data_flag`。超时参数见下方 Daemon 说明；失联清零数据和标志，再收有效帧恢复。
- 接收前检查 `DT7_Online()`；开关清零状态不属于有效档位。
- 使用 TIM5，超时换算与边界见 [Daemon](../daemon/README.md)。需要实际接入时另行分配符合参数的 UART，本次不改生成外设配置。
