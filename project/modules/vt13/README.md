# VT13 图传遥控器

独立模块；本项目应用层由 `Cmd_Init()` 在现有 USART3 上调用 `VT13_Init(&huart3)`。串口须为 921600、8N1、接收使能；参数不符返回 `nullptr` 并记录错误，不注册接收。

- `VT13_Init()` 返回只读帧指针；数据也可由 `vt13_data` / `VT13_RC_*` / `VT13_KEY_*` / `VT13_MOUSE_*` 读取，具体字段见 [vt13.h](vt13.h)。
- 仅接收完整 21 字节、帧头 `A9 53` 且 CRC16 正确的帧。无效帧不覆盖状态、不喂狗；沿用源版，不另加摇杆范围校验或流式拆包。
- 初始化后保持离线，首个有效帧才上线并置 `vt13_data_flag`；有效帧间超时见下方 Daemon 说明。失联清零整帧及标志，重新收到有效帧即可恢复。
- 读取控制量前必须检查 `VT13_Online()`；清零后的原始通道并非 1024 中位，不能直接当作中立摇杆。应用层仍由在线状态与 C 档共同控制使能。
- 接收与 Serial 满缓冲检测共用 TIM5；超时换算及触发边界见 [Daemon](../daemon/README.md)。

[DT7](../dt7/README.md) 是另一独立模块，不复用本模块的帧或接口。
