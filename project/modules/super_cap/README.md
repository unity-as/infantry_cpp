# 超电接入接口

[SuperCap](super_cap.h) 目前只提供已解码反馈的交接与 Daemon 在线判定，不包含 CAN ID、帧布局或实际发送。
本车协议尚未确定，不沿用其他项目报文。`Command` 表达输入功率目标，留待协议适配，不代表已下发或硬件已执行。

静态持有对象并在外设就绪后 `init()`，传入 Daemon 定时器和毫秒超时。初始化保持离线；协议解析器仅在有效新样本到达时调用
`receive()`，非有限功率不喂狗。功率是超电向底盘输出侧的电功率，允许保留带符号观测，不能当作裁判输入功率。
`isOnline()` 失效后缓存值保留，使用方不得再把它作为当前实测值。

当前底盘配置的超电指针为空，没有初始化超电对象或注册总线收发。后续协议适配在本模块完成；
同步样本与 RLS 使用约定见 [底盘](../../application/chassis/README.md#功率与积分回灌)。
