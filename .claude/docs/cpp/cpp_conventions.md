# C++ 编程规范

本文件是编码、对象生命周期、头文件和实例类布局的唯一规范。当前接口入口见 [API 导航](../../conventions/api.md)，目录依赖见 [工程结构](../../conventions/file.md)。规则适用于自维护代码，生成代码和第三方库不做批量风格整理。

## 基本约束

- 固件采用 C++20；编译配置见 [CMakeLists.txt](../../../CMakeLists.txt) 与 [ARM 工具链](../../../cmake/gcc-arm-none-eabi.cmake)。
- 自维护模块禁止 `malloc/free/new/delete`、动态 STL 容器和智能指针；长期对象用全局或静态，临时值对象放栈上。RTOS 自身分配机制不在这条源码风格约定的替换范围内。
- 禁异常、RTTI 和 `std::function`。错误通过状态或返回值交给调用者处理，不以运行期 `assert/abort` 作为固件错误处理；编译期约束可用 `static_assert`。主机测试的断言不受固件运行方式限制。
- C → C++ 迁移或纯风格整理不得顺带改变算法、单位、数据流、回调顺序和保护行为；功能修改需有对应任务授权。

## 命名与文件

| 对象 | 约定 |
|---|---|
| 文件 | 小写下划线；普通模块 `.h` + `.cpp`，纯模板 header-only 可用 `.hpp` |
| 类、嵌套类型 | 大驼峰；缩写保留大写，如 `DJIMotor`、`Config` |
| 成员函数 | 小驼峰；同类设备尽量统一语义和单位 |
| 成员变量 | 小写下划线，末尾 `_` |
| 局部变量、参数 | 小写下划线，无末尾 `_` |
| 模板参数 | 前置下划线，如 `_rows` |
| 宏 | 大写下划线 |

已有应用层自由函数和全局指令保留其接口形式，不为套用类模板强制重构。命名规范是新增和修改时的约定，不表示所有旧文件均已符合。

## 头文件防重复包含

自维护 C/C++ 头文件统一使用 `#pragma once`，放在文件说明之后、include 之前，不再同时保留外层头文件守卫。功能选择、平台适配和 C 链接边界的条件编译保留。

## 对象与回调

有长期状态的实例类以全局或静态对象声明，构造只初始化数据；HAL 就绪后由上层填入嵌套 `Config`，调用 `init(config)` 完成外设注册，再调用成员函数。矩阵、向量等临时值对象可直接构造。

跨模块确需读取的状态按既有接口开放；HAL 句柄、缓冲和回调等内部机制保持私有。内部辅助逻辑归入类的私有方法。外设事件回调使用函数指针及 `void* device` 上下文，按接口通过 `setCallback` 或 `Config` 传入，不引入类型擦除回调。

具体模块可采用不同形式：例如当前 KF/EKF 接收调用方已经算好的模型矩阵，不使用旧姿态回调。调用时必须查真实头文件。

## 实例类成员排列

数据优先是为了便于在 Ozone 中集中查看实例状态、目标和控制量。适用于电机、Daemon、Axis、KF、PID、传感器和 BSP 等有状态实例；KF 使用矩阵也仍适用。

类体按以下顺序排列：

1. 嵌套类型：`using`、`enum`、`Config`、原始反馈结构等。
2. 实例数据成员。
3. 静态数据成员，包括 `static constexpr` 常量。
4. 静态成员函数，包括中断入口和回调转接。
5. 实例成员函数，包括构造、析构、访问器、运算符和私有辅助方法。

各组内按 `public` → `protected`（如有）→ `private` 分段，允许重复访问标签。所有数据声明完成后再声明或定义函数，内联函数同样放在函数区。函数指针和上下文指针属于数据，回调类型别名属于嵌套类型。

整理时保留字段相对顺序、权限、默认值和控制逻辑。矩阵、向量等纯数学值类型（如 `Matrixf`）不强制按实例类顺序重排；这个例外不豁免头文件约定。

## 语言特性与风格

- 可用模板、继承、虚函数、`override/final`、`constexpr/static_assert`、`auto`、范围 for、`nullptr`、默认或删除成员函数、`explicit`、标准类型转换及属性。
- 无堆的 `std::array/optional/pair/tuple` 可选；`mutable`、对齐声明、`consteval/constinit` 按需求使用。
- 保留既有禁用项：移动语义、`std::bit_cast`、concept、`thread_local`、用户定义字面量；`friend` 仅在标量左操作数等必要运算符场景使用。
- 采用 4 空格、K&R 大括号、运算符两侧留空格、`Type* ptr` / `Type& ref`，行宽目标 120 字符。
- 注释用中文，标识符用英文；接口用 Doxygen 标签解释单位、坐标、前置条件和失败行为，避免复述语句。
- C 链接声明仅用于真实 C/C++ 边界，纯 C++ 模块之间不增加 `extern "C"`。

## 二进制协议

接收缓冲中的字节先按已核对的协议布局复制到对象，再读取字段；不要通过强转缓冲指针直接解引用结构体或浮点值。使用 `memcpy` 仍需核对长度、端序、packed 布局及字段有效性。位域布局依赖编译器，不能单靠一份位域声明证明跨工具链的报文一致。

当前协议说明和测试入口见 [裁判](../../../project/modules/referee/README.md)、[VT13](../../../project/modules/vt13/README.md)、[主机回归](../../../tools/tests/leg_sync/README.md)。
