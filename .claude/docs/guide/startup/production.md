# 整车启动与操作检查

这是按当前源码整理的操作清单，整套流程尚未作为上场流程完成实机验收。已测版本及缺口见 [验证记录](../../../records/validation.md)，当前待确认项见 [待办](../../../records/todo/current.md#待验证边界)。烧录步骤见 [开发启动](debug.md)。

## 上电前

1. 核对准备运行的固件版本与 [config.h](../../../../project/application/config.h) 的初始化开关，确认本次启用哪些机构。开关含义见 [系统架构](../../impl/architecture.md#初始化流程)。
2. 按 [硬件事实](../../../conventions/hardware.md) 核对接线；检查云台机械空间、编码器零位和两类 pitch 限位配置。尚无独立机械端点标定结论，不把配置范围当成实测端点。
3. 使用当前应用接入的 VT13，先置于 C 挡失能，保持车体可控、机构无干涉。DT7 模块存在不代表已经替代应用输入。

## 上电与使能

保持 IMU 静止，等待 AHRS 同步预热和校准完成，再等待 cmd 启动延迟。预热、重采与超时行为见 [AHRS](../../../../project/modules/ahrs/README.md#启动预热与校准)，不能只按一个固定秒数判断启动成功。

[Cmd_Task](../../../../project/application/cmd/cmd.cpp) 在 VT13 在线且开关非 C 挡时使能云台、底盘及已初始化的发射机构。S 挡选底盘跟随，其余已使能挡选无旋转模式；控制符号以 VT13 模块的枚举和实际遥控器映射核对。

先验证失能/遥控断联能停止输出，再小幅检查底盘前后、横移与旋转，云台方向和边界。出现方向、在线状态或机械约束不符时回到失能，记录状态后处理。

## 遥控与键鼠

| 操作 | 当前代码行为 |
|---|---|
| 左摇杆 | 底盘移动；方向与云台角组合 |
| 右摇杆 | 累加云台姿态目标 |
| 拨轮 | 无旋转模式下的手动旋转指令 |
| 鼠标移动 | 切入键鼠模式并累加云台目标；摇杆有输入时可切回遥控 |
| WASD | 键鼠底盘移动，对角速度归一化 |
| 右 FN / 鼠标右键 | 按 [自瞄契约](../../impl/aim.md)进入自瞄 |
| 扳机 / 鼠标左键 | 提交发射请求；门控和未实现保护见 [发射](../../../../project/application/shoot/README.md) |

## 外部系统检查

裁判缓存参与底盘限功率、弹速和颜色上报；RGB 展示缓冲能量，不能只凭灯色判断协议或保护正常。小电脑在线不代表识别到目标。首帧、失联和功率边界分别见 [Daemon](../../../../project/modules/daemon/README.md#调用方)、[底盘](../../../../project/application/chassis/README.md#功率与积分回灌)与 [自瞄](../../impl/aim.md#开火与丢失边界)。

记录本次固件、启用配置、输入设备、实际检查工况和结果；仅在真实执行后更新验证记录。尚未完成的热量保护、丢失策略等仍按待办跟进，不能因本清单已补齐而标为功能通过。
