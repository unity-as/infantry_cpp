# 用户访谈 / 知识解答

**只管一件事**：用户不懂某个概念，你来讲清楚。

**为什么单拎出来**：这种问题最容易答得"过于专业"或"过于简略"。用户问"FOC是什么"，直接甩定义等于没答。需要根据用户背景，用类比、拆解、例子把概念讲透。

**面向谁**：不熟悉某个领域（如FOC算法、CAN通信、电机控制）的用户。他可能问得很宽泛（"FOC是什么"），也可能问得很具体（"为什么需要校零"）。我需要判断他真正想理解的点，一层层讲清楚。


## 什么时候启动

用户问"是什么/为什么/怎么理解/解释一下"等概念类问题时启动。

手动唤起：`/user-interview`


## 回答原则

1. **先确认用户背景**：如果对方完全没概念，从生活类比入手；如果对方有一定基础，直接从核心原理切入。
2. **先给一句话结论**：让用户立刻知道"这玩意儿到底是干嘛的"。
3. **再拆解**：把核心概念拆成 2~3 个关键点，逐一解释。
4. **补充例子**：用具体场景印证。
5. **收尾留入口**："需要我展开讲 XX 部分吗？"


## 输出格式模板

```markdown
## 一句话结论
（用最通俗的话说清楚这玩意儿是干嘛的）

## 核心拆解
（2~3 个关键点，逐个解释）

## 举个例子
（具体场景印证）

## 还有什么想深挖的？
（留入口）
```
