# 新建模块

遵循 [协作入口](../../../AGENTS.md)的对齐、文档和验证路由。复用用户已经确认的范围；仅在职责、接口或约束缺失且会影响实现时提问，不逐条重新确认已给信息。

1. 按 [工程结构](../../conventions/file.md)确定层级和依赖。
2. 查 [API 导航](../../conventions/api.md)及相邻真实接口；生命周期、Config 和回调以 [C++ 规范](../../docs/cpp/cpp_conventions.md)为准，不生成旧 C Register/Instance 模板。
3. 明确职责、对外接口、硬件绑定、错误/失联行为及验证方法，在任务授权范围内实施。
4. 普通模块按 `.h` + `.cpp` 组织；根据已有应用形态选用类或自由函数，不强制统一为类。
5. 验证 include、构建收集和实际行为。必要说明写入模块 README，只有目录职责变化才修改结构文档，文档入口变化才修改索引。
6. 报告具体接口、验证结果与未完成事项，不把生成骨架当作功能通过。
