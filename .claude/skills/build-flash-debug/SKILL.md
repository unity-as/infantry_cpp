# 构建、烧录与调试

先读取 [开发启动](../../docs/guide/startup/debug.md)，命令、产物和本机设置边界只在该文档维护，不在技能复制另一套命令。

1. 确认用户请求的是构建、烧录、调试还是配置环境；已有明确授权持续有效。只请求文档或编译不构成烧录授权。
2. 读取相关 preset、工具链及本机工具路径；首次构建先配置，后续使用已有的正确构建目录。
3. 烧录前确认 ELF 与目标板、探针及所需版本一致；缺少固件时在已授权范围内先构建。执行后记录实际 verify 和复位结果。
4. Ozone 先核对脚本里的固定探针序列号及源码路径；VS Code 的个人设置不能当作仓库已经提供的通用环境。
5. 失败时查实际错误和对应配置，不原样反复重试。报告构建、写入、调试连接与实车验证各自的结果和边界。

改动配置、烧录和验证分别遵守 [协作入口](../../../AGENTS.md)所路由的技能；修改权限不由本技能扩展。
