# RoboMaster 图传模块 (VT03&VT13) 用户手册 - 详细参考文档

**文档版本**：v1.0
**更新日期**：2025.04
**产品名称**：RoboMaster 图传模块 (Video Transmission Module VT03&VT13)

---

## 1. 基本信息与概述
*   **简介**：RoboMaster 裁判系统相机图传模块（包括发送端和接收端）是一套实时高清图像采集和无线传输系统。具有高清晰度、高帧率、低延迟的特点，支持多套图传模块同时工作。可为用户提供机器人的第一人称视角。注意：图传模块**不可独立使用**，需接入裁判系统。

## 3. 机械安装与尺寸
### 3.1 发送端安装
*   **安装方式**：按需选择孔位进行安装，使用 **M3 螺丝** 将发送端固定至适当位置。
*   **安装注意事项**：
    *   不能遮挡发送端的进风口（部件2）与出风口（部件4）。
    *   发送端的天线（部件3）周围**不能有任何金属遮挡**。

### 3.2 接收端尺寸
*   接收端无需安装，外形物理尺寸参考：宽度约 150mm，高度约 130mm（含天线）。

### 4.2 配对（对频）与使用
*   **中国及其它非日本地区**：
    1.  确保裁判系统电源管理模块连接至主控模块。
    2.  启动发送端：使用航空转接线将发送端连接到裁判系统电源管理模块。启动后指示灯为**红灯闪烁**（每秒1次）。
    3.  启动接收端：短按一次电源键，再长按2秒。
    4.  **触发对频**：
        *   发送端：在裁判系统主控模块上点击 `模块设置 > 图传对频`。对频后发送端指示灯变为**蓝灯闪烁**（每秒1次）。
        *   接收端：先长按电源键直至听到“嘟”的一声（约2秒），短暂松开后再次长按电源键（约2秒）。当接收端持续发出“嘟...嘟...嘟”的提示音，发送端变为**绿灯闪烁**（每秒1次），接收端发出“嘟噜”两声后静音时，代表对频成功。
    5.  **查看图像**：将接收端 USB-C 接口连接至电脑，打开 RoboMaster Client 软件，即可查看图像画面。
*   **日本地区**：
    1.  确保供电正常。
    2.  启动发送端：连接后指示灯为**橙灯常亮**。
    3.  启动接收端：短按再长按电源键。
    4.  在裁判系统主控模块上正确设置机器人 ID。
    5.  将接收端连接电脑，打开 RoboMaster Client 选择对应机器人 ID 登录查看画面。
*   **提示**：接收端断电重启后与发送端的连接状态保持，但若断电重启后需重做步骤 3 至 5 重新对频。

### 4.3 同步运行模式
*   **说明**：日本地区不支持此功能。同时使用多套图传模块时，可开启同步运行模式以提升图传性能、减小干扰。
*   **操作步骤**：
    1.  准备同步桩：将一台发送端通过主控模块连接至电脑，打开 `RoboMaster Tool 2` 选择“同步桩设置”，将发送端配置为同步桩。
    2.  开启：在裁判系统主控模块上勾选 `调试设置 > 图传同步运行模式`。

## 5. 通信协议与遥控数据 (UART)
*   **协议说明**：与发送端连接后，接收端可作为**遥控器**发送控制数据。该数据可通过接收端的 **UART** 接口输出一帧 **21 字节**的数据，每 **14ms** 发送一帧。**USB连接电脑开启 RoboMaster Client 后**，底层的鼠标/键盘数据也会通过 UART 透传并发回。

## 8. 其它注意事项与固件升级
*   **固件升级**：发送端核心版本/接收端固件使用 **DJI Assistant 2 (RoboMaster Series)** 升级。发送端固件通过 **RoboMaster Tool 2** 升级。
*   **升级警告**：必须按步骤升级，升级过程中电脑需访问互联网，升级过程中请勿插拔 USB 数据线。升级接收端固件时，确保接收端电量充足。
*   **使用警告**：
    1. 请确保各接口按照说明正确连接，以免导致模块损坏。
    2. 使用过程中，请注意避开 5 GHz 频段无线设备的干扰，以免影响传输质量。
    3. **同一环境下最多可同时使用 8 套相机图传模块**，否则可能导致图像质量下降，甚至发生卡顿或断连。多套图传模块同时工作时，建议使用同步运行模式。
