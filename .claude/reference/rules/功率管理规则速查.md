## 一、射击热量机制

> 超对抗 §5.1.3；联盟赛也有（同机制，见其 §3.3.1）

- 每发 **17mm** 弹丸：当前热量 **+10**（与射击初速度无关）
- 每发 **42mm** 弹丸：当前热量 **+100**
- 冷却按 **10Hz** 结算，每周期冷却值 = 每秒冷却值 / 10
- 设上限 `Q0`、当前热量 `Q1`：

| 区间 | 后果 |
|---|---|
| Q1 ≤ Q0 | 正常发弹 |
| Q0 < Q1 ≤ Q2 | 图传断开 + 发射机构锁定，**冷却到 Q1=0 才解锁** |
| Q1 > Q2 | **当局永久锁死，不再解锁** |

- Q2 = Q0 + 100（17mm）/ Q0 + 200（42mm）
- 战亡时热量重置为 0

**策略**：Q0 是绝对红线，永不触碰。可持续射频 = 每秒冷却值 / 每发热量（17mm 即 `冷却值/10`）。

### 裁判系统对应字段

| 字段 | 来源帧 | 含义 |
|---|---|---|
| `shooter_barrel_cooling_value` | 0x0201 | 每秒冷却值 |
| `shooter_barrel_heat_limit` | 0x0201 | 热量上限 Q0 |
| `shooter_17mm_barrel_heat` | 0x0202 | 17mm 当前热量 |
| `shooter_42mm_barrel_heat` | 0x0202 | 42mm 当前热量 |

> 各等级/发射机构类型的基础上限与冷却速率见规则手册 表5-13（英雄）、表5-15（步兵17mm）、表5-16（空中）。裁判下发的值为**含增益后的当前值**。

## 二、底盘功率超限（缓冲能量）

> 超对抗 §5.1.4；联盟赛 §3.3.1.4（两赛规则一致）

- 结算频率 **10Hz**
- 缓冲能量上限 **Q = 60 J**
- 超功率 → 扣缓冲能量；缓冲耗尽仍超限 → **底盘断电 5 秒**
- 不超限时缓冲缓慢回充
- 战亡时缓冲重置为上限

**策略**：缓冲是瞬时超功率的「避震器」，弹射起步/急转弯的短尖峰靠它吸收；但别抽干（否则断电 5 秒）。

### 裁判系统对应字段

| 字段 | 来源帧 | 含义 |
|---|---|---|
| `chassis_power_limit` | 0x0201 | 底盘功率上限 P0（W） |
| `buffer_energy` | 0x0202 | 当前缓冲能量（J） |

> ⚠️ 2026 协议 0x0202 帧前 8 字节为「保留位」，**底盘当前功率不再下发**，需自行从电机电流估算（P = Σ Kt·I·ω，机械功率，负功率/倒灌算 0）。

## 三、超级电容（物理硬件）

> 制作规范手册 §3.12、S5、S6、S186

- 标称能量 **≤ 2000 J**，实测能量 **≤ 2200 J**（S6）
- 标称能量公式：**E = ½ · C · U²**（C 容值，U 耐压值）
- 每台机器人最多 **1 组**超级电容模组（S5）
- 英雄/步兵/哨兵**均需**安装超级电容管理模块（S186）
- 超级电容管理模块：检测容值、实时监控输入/输出能量
- 作用：**削峰填谷**——瞬时大功率时放电，空闲时充电

## 四、底盘能量机制 / 节能（**仅 RMUC 超级对抗赛**）

> 超对抗 §5.6.7；联盟赛**无此机制**

- 初始底盘能量 **20000 J**，上限 **40000 J**
- 消耗：Chassis 接口每输出 1 J → 底盘能量 −1
- 耗尽（=0）→ **节能状态**，底盘功率上限基础值 **35 W**
- ≥25000 → 底盘功率上限基础值 **×1.25**（最高不超过 200 W）
- 补充：① 占领补给区无线充电；② 超级电容充电净输入每 1 J → 底盘能量 **+8**

> ⚠️ 易混淆点：「底盘能量」（20000~40000 J，规则机制）≠「超级电容」（≤2000 J，物理硬件）。两者通过充电按 8:1 耦合，别混为一谈。

## 五、RMUL（联盟赛） vs RMUC（超级对抗赛）对比

| 机制 | RMUC | RMUL |
|---|---|---|
| 射击热量超限和冷却 | ✅ | ✅ |
| 底盘功率超限（缓冲 60J + 断电 5 秒） | ✅ | ✅ |
| 超级电容管理模块离线扣血 | ✅ | ✅ |
| 底盘能量机制（20000/40000J） | ✅ | ❌ 无 |
| 节能状态（耗尽 → 35W） | ✅ | ❌ 无 |
| ≥25000 → 功率 ×1.25 加成 | ✅ | ❌ 无 |
