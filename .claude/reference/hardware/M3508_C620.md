# M3508 直流无刷减速电机 + C620 电调 组合参考手册

> 本资料整理自 RoboMaster M3508 电机 User Guide（V1.0 2017.08）及 C620 电调 User Guide（V1.0 2017.09）
> 用途：`reference/hardware/M3508_C620.md`
> 定位：功能/安装/参数参考手册


## 一、组合概述

M3508 直流无刷减速电机与 C620 无刷电机调速器是 RoboMaster 官方配套动力组合。

- 减速比：**19:1**（359/19）
- 输入电压：**DC 24V**
- C620 最高持续电流：**20A**
- 控制方式：**CAN 总线** 或 **PWM**（50-500Hz）
- 支持通过 CAN 总线获取转子位置、转速、温度


## 二、接口与连线

### 电机接口
- **7-Pin 数据端口**：连接电调进行数据交互
- **三相动力线接头**：与电调三相线同色匹配连接

### 电调接口（C620）

| 接口 | 功能 |
|------|------|
| 7-Pin 电机数据端口 | 连接 M3508 |
| 三相动力线接头 | 同色匹配 |
| CAN 终端电阻开关 | ON=接入120Ω |
| SET 按键 | ID设置 / 电机校准 |
| 电源线 | XT30，24V |
| 指示灯 | 状态指示 |
| CAN 信号端口 | CAN_H/CAN_L，1Mbps |
| PWM 信号端口 | PWM控制 / 串口调参 |

### 接线步骤
1. 7-Pin 数据线连接电机和电调
2. 三相线同色匹配连接（不可逆接头正确匹配）
3. CAN 或 PWM 信号线接入目标接口
4. 连接 24V 电源

> ⚠️ 禁止同时接入 CAN 和 PWM，切换必须断电操作。


## 三、安装尺寸

### 电机安装孔
- **3 × M4 螺纹孔**，深度 10mm
- 分布：120° 均匀分布

> ⚠️ 螺丝深度不得超过 10mm，否则可能顶坏减速箱外齿圈。


## 四、指示灯（C620）

### 正常状态
| 显示 | 含义 |
|------|------|
| 绿灯每隔1秒闪N次 | ID = N（1~8） |

### 设置/校准状态
| 显示 | 含义 |
|------|------|
| 橙灯常亮 | 快速设置ID模式 |
| 绿灯快闪 | 电机校准模式 |
| 绿灯常亮 | PWM信号校准中 |
| 橙灯快闪 | PWM校准失败 |

### 警告状态
| 显示 | 含义 |
|------|------|
| 橙灯每隔1秒闪1次 | 电机温度125℃ |
| 橙灯每隔1秒闪2次 | 总线有相同ID |
| 橙灯每隔1秒闪3次 | PWM输入不在最小值 |

### 异常状态
| 显示 | 含义 |
|------|------|
| 红灯常亮 | 无法访问电机存储器（开机自检） |
| 红灯每隔1秒闪1次 | 供电电压过高（开机自检） |
| 红灯每隔1秒闪2次 | 三相线未接入 / 7-Pin数据异常 |
| 红灯每隔1秒闪3次 | 丢失位置传感器数据 |
| 红灯每隔1秒闪4次 | 电机温度130℃ |
| 红灯快闪 | 电机校准失败 |


## 五、SET按键操作

### 独立设置ID（单个）
1. 正常工作状态下短按1次 SET → 进入独立设置ID模式，指示灯熄灭
2. 短按 SET 按键次数（≤8次）= ID号，每次有效短按橙灯闪1次
3. 3秒无操作自动保存
4. 重新上电生效

> ⚠️ 同一总线不可有重复ID，否则冲突电调关闭输出。

### 快速设置ID（批量）
1. 短按总线上任意1个电调的 SET 进入独立ID模式
2. 长按 SET → 所有电调进入快速设置ID模式，橙灯常亮
3. 按预定顺序依次手动转动对应电机转子（至少半圈）
4. 电调按转动顺序自动从1开始编号
5. 编号完成者重新上电生效

> ⚠️ 未被转动转子的电调保持原有ID。

### 电机校准
1. 电调与电机连接并上电
2. 长按 SET 直至绿灯快闪，释放
3. 自动校准，完成后自动退出

> ⚠️ 校准时会转动，空载进行。多次失败请更换电机。


## 六、CAN通信协议

> 比特率：1Mbps

### 接收报文（控制电流输出）

**标识符：0x200**（控制 ID 1~4）

| 字节 | DATA[0-1] | DATA[2-3] | DATA[4-5] | DATA[6-7] |
|------|-----------|-----------|-----------|-----------|
| 内容 | 电流高/低8位 | 电流高/低8位 | 电流高/低8位 | 电流高/低8位 |
| 对应ID | 1 | 2 | 3 | 4 |

**标识符：0x1FF**（控制 ID 5~8）

| 字节 | DATA[0-1] | DATA[2-3] | DATA[4-5] | DATA[6-7] |
|------|-----------|-----------|-----------|-----------|
| 内容 | 电流高/低8位 | 电流高/低8位 | 电流高/低8位 | 电流高/低8位 |
| 对应ID | 5 | 6 | 7 | 8 |

**给定值范围**：`-16384 ~ 0 ~ 16384` ↔ `-20A ~ 0 ~ 20A`（线性映射）

换算公式：`实际电流 = (给定值 / 16384) × 20A`

### 反馈报文

**标识符：`0x200 + 电调ID`**（如 ID1 → 0x201）
**频率：1kHz**

| 字节 | DATA[0-1] | DATA[2-3] | DATA[4-5] | DATA[6] |
|------|-----------|-----------|-----------|---------|
| 内容 | 机械角度高/低8位 | 转速高/低8位 | 转矩电流高/低8位 | 电机温度 |

| 字段 | 范围/说明 |
|------|-----------|
| 机械角度 | 0 ~ 8191 |
| 转速 | rpm |
| 转矩电流 | `-20A ~ 0 ~ 20A`，线性映射 |
| 电机温度 | ℃ |


## 七、PWM控制

| 参数 | 规格 |
|------|------|
| 允许频率 | 50 ~ 500Hz |
| 控制方式 | 脉宽调制信号 |
| 切换控制方式 | 必须断电后切换 |

> ⚠️ 运行中不可切换控制方式。

## 九、使用注意事项

1. 避免杂物进入转子内部
2. 接线正确、安装稳固
3. 在绕组最大允许温度（125℃）内使用
4. 避免损伤线材
5. 请勿触摸转子，避免割伤
6. 大功率输出时注意烫伤
7. 电机安装螺丝深度不得超过 10mm
8. 禁止同时接入 CAN 和 PWM
9. 切换控制方式必须断电操作
10. 避免长时间过热
