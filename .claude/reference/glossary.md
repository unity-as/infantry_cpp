## 一、RoboMaster 术语

### 兵种（机器人）

| 术语 | 定义 |
|------|------|
| 英雄机器人 | 战场上唯一可以发射 **42mm 弹丸**的机器人。英雄机器人在场地指定位置攻击基地时有额外的攻击效果。每队 **1 台**，由 **1 名操作手**控制。 |
| 步兵机器人 | 发射 **17mm 弹丸**的地面主战兵种。每队 **2~3 台**（视赛事阶段而定），是战队的主要战斗力量。 |
| 工程机器人 | 负责**获取、搬运弹丸**，为步兵和英雄机器人兑换弹丸，并可**救援**地面阵亡机器人。不能攻击，但防御较高。每队 **1 台**。 |
| 哨兵机器人 | 全自动机器人（**0 名操作手**），在哨兵轨道上自主移动和反击。发射 17mm 弹丸对敌方目标进行自主反击。每队 **1 台**。 |
| 空中机器人 | 从空中对地面进行火力压制，可配置机动 17mm 发射机构。仅云台手可用外部控制器。每队 **1 台**。 |
| 飞镖系统 | 发射飞镖射击前哨站和基地的远程攻击系统。 |
| 雷达 | 通过视觉摄像头或激光雷达探测对手，为团队提供赛场全局视野。 |
| 基地机器人 | 相当于 MOBA 游戏中的**水晶/大本营**，胜负关键。基地血量为 **5000**。可发射 17mm 弹丸进行自主反击。每队 **1 台**。 |

### 弹丸

| 术语 | 定义 |
|------|------|
| 17mm 弹丸 | 球形，黄绿色，直径 **16.8mm ± 0.2mm**，质量 **3.2g ± 0.1g**，材质为塑胶 TPU。由步兵、哨兵、空中机器人使用。俗称“**小弹丸**”。 |
| 42mm 弹丸 | 与高尔夫球外形相似，白色，直径 **42.5mm ± 0.5mm**，质量 **41g ± 1g**，材质为塑胶 TPE。**仅英雄机器人可发射**。俗称“**大弹丸**”。 |
| 荧光弹丸 | 比赛中使用的 17mm 荧光弹丸，17mm 枪管需加装充能装置。 |
| 发光弹丸 | 42mm 发光弹丸，比赛中使用。 |

### 场地与机制

| 术语 | 定义 |
|------|------|
| 启动区 | 比赛正式开始前机器人的放置区域。 |
| 基地区 | 基地机器人所在区域，分为红方基地和蓝方基地。 |
| 补给区 | 机器人弹丸补给、血量恢复的重要区域。步兵机器人可在比赛中补给 17mm 弹丸。 |
| 补给禁区 | 一方补给点相对对方机器人是补给禁区，不得进入。 |
| 资源岛 | 战场中心的公共资源区，包含弹药库和能量机关，不分红蓝方。 |
| 前哨站 | 位于哨兵轨道前方，上限血量 **2500**，分为红方前哨站和蓝方前哨站。 |
| 能量机关 | 由 **4 个**贴有数字 Mark 的靶子组成（或 5 片扇叶装甲板），机器人需按顺序依次击倒以激活 Buff 加成。激活小能量机关可获得 **50%** 攻击力增益，大能量机关可获得 **100%** 攻击力增益和 **50%** 防御增益。 |
| 中心增益点 | 位于战场中心位置。 |
| 装甲模块 | 机器人端的伤害感知系统，通过压力传感器并结合装甲板震动频率检测弹丸攻击。分为大装甲模块（AM11）和小装甲模块（AM01）。 |
| 测速模块 | 实时测量弹丸的速度和频率，分为 17mm 和 42mm 两种规格。测速范围 **1~50m/s**，测频范围 **1~50Hz**。 |
| 裁判系统 | 全自动监控机器人状态并做出判决的电子系统，监控血量、弹丸初速度、底盘功率、位置等信息。 |
| 主控模块 | 裁判系统的核心控制单元，监控整个系统运行状态。 |
| 运动控制器模块 | 连接装甲模块、电源、图传模块的枢纽，将操作手指令通过 UART 接口传输至机器人。 |
| 图传模块 | 通过摄像头实时捕捉机器人前方画面，将第一人称视角画面回传到操作间显示屏。 |
| 定位模块 | 与场地基站通信实现定位，为比赛地理围栏提供依据。 |
| 灯条模块 | 机器人端监控装置的运算单元，实时显示机器人血量。 |
| 场地交互模块 | 用于机器人与场地交互（如刷卡复活、占领增益点等）。 |
| 枪口热量 | 限制机器人连续射击的机制，发射弹丸会产生枪口热量，热量超限后无法继续射击。 |
| 底盘功率 | 机器人底盘电机的功率上限，超限会受到惩罚。 |
| 经验与性能体系 | 步兵和英雄机器人可通过升级获得性能点，从上限血量、底盘功率、弹丸初速度上限三方面进行提升。 |

## 二、机甲结构

| 术语 | 定义 |
|------|------|
| 底盘 | 机甲的移动机构，包含轮毂电机、悬挂系统、底盘框架。负责机甲的平移、旋转、加速等运动。控制层面通常处理**底盘功率**和**运动学解算**。 |
| 云台 | 安装在底盘上方的二轴或三轴稳定平台（俯仰轴 + 偏航轴，部分含横滚轴），承载发射机构和主控板。云台通过电机控制实现**枪口稳像**和**瞄准**，独立于底盘运动。 |
| 发射机构 | 安装在云台上的弹丸发射装置，包含摩擦轮、供弹链路、拨弹盘。控制层面通常涉及**枪口热量管理**和**射速控制**。 |
| 主控板 | 机器人的核心计算与控制单元（通常是 STM32 系列）。**主控板一般安装在云台上**，而非底盘，以确保与发射机构和云台电机的连接线最短，同时避免底盘变形/振动对主控板的影响。 |
